# Bankboeker (online)

De online versie van Endura's Bankboeker, geserveerd via GitHub Pages op
https://sher-endura.github.io/bankboeker-app/ — gelinkt vanuit het E-Board-menu.

Deze map wordt gevuld vanuit de werkmap `Bankboeker-web` (privérepo
Sher-endura/bankboeker): `index.html` en `config.js` zijn kopieën,
`seed_t2pan.js` is hier bewust leeg (geen klantgegevens in een publieke repo).
Inloggen: eigen Bankboeker-accounts (@endura-aruba.com), beheerd in de app zelf.
